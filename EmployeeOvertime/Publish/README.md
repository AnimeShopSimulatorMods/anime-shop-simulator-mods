# Employee Overtime

A MelonLoader mod for **Anime Shop Simulator** that keeps your employees working after the store closes.

## Features

- **Work after closing time** — Employees keep restocking shelves, sorting storage and cleaning after closing time, until you end the day.
- **Normal next day** — The next day starts exactly as it would without the mod.
- **Toggle** — Turn the mod on or off in `UserData/MelonPreferences.cfg` (`[EmployeeOvertime] Enabled`).

## Requirements

- [MelonLoader](https://github.com/LavaGang/MelonLoader) 0.7.x (tested on 0.7.3)

## Installation

1. Install MelonLoader into Anime Shop Simulator and launch the game once.
2. Copy `EmployeeOvertime.dll` into the game's `Mods` folder.
3. Launch the game. The MelonLoader console should show `Employee Overtime`.

## Configuration

`UserData/MelonPreferences.cfg`, created after the first launch:

```
[EmployeeOvertime]
Enabled = true
VerboseLogs = true
```
